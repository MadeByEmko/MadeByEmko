---

### Jak pracuju

- **Web na míru, ne ze šablony.** Bez WordPressu a hromady pluginů, které je potřeba pořád aktualizovat.
- **Vlastní administrace.** Texty, fotky, ceny i nabídku si klient upraví sám, bez volání programátorovi.
- **Mobile‑first.** Web navrhuju nejdřív pro telefon, pak pro počítač.
- **Přímá komunikace.** Žádná agentura. Klient píše přímo člověku, který web dělá.
- **Termín předem.** Termín dodání je v nabídce ještě před začátkem práce.

```bash
$ git log --reverse --oneline
krok-01  Úvodní hovor a nabídka
krok-02  Návrh vzhledu
krok-03  Vývoj a obsah (rozpracovaná verze je celou dobu online)
krok-04  Spuštění na doméně klienta
```
